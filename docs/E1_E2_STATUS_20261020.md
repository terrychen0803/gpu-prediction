# 固定輸入 E1 與 E2 進度（2026-10-20）

GB10、RTX 3090、RTX 4090 已使用同一 FP16 輸入、權重、量測程式與設定完成 ResNet50 E1：每台 B1/B8/B32 × G/A/P0/P1 × 三個獨立程序，共 108 個正式 run。108/108 execution、worker quality、correctness 與跨設備協定檢查通過；九組 G 的三程序 spread 均低於 5%。5090 尚未可用，故四設備矩陣仍未完成。

數字是每程序正式 iteration 中位數，再對三程序取中位數；一次請求是一個完整 batch 的 host forward 加最後同步。完整原始 session、checksum、排除與倍率分析只存於 GB10 的 `/home/good_egg/RTchen/`，不提交 Git。54 份 P0/P1 trace 的 parser 通過，但全都有「CUDA 事件可能未完整收集」警告，其中 27 份另有 NVTX 警告；`manual_review_required` 尚未解除。G 無 profiler 的服務時間比較可先使用，細粒度 trace 結論仍為探索性。

E2 的 [Compute／Memory／Launch／Host 校正工具](../e2_calibration/README.md)已實作。GB10 以 `e2_calibration_v3` 收 100 個 cell、三個獨立程序、每 cell 每程序五群，共 1,500 組原始計時，沒有低於 80 ms 的群組；少量 Nsight trace 已驗證 native empty、short、copy kernel 各 10 筆。98/100 個 cell 的三程序 spread 不超過 10%；兩個 memory write cell 在完整矩陣中有較大波動，另做三程序補測後分別為 3.52% 與 3.90%。補測未回填完整矩陣；兩格暫不選作建模錨點。GB10 實測報告位於本機 `analysis_runs/three_gpu_fixed_input_e1_20261020/E2_GB10_REPORT.md`。

RTX 3090／4090 尚無 E2 實測。兩台節點應依 [E2 節點操作手冊](E2_NODE_RUNBOOK.md)在本機先跑 smoke，再跑正式校正與獨立 Nsight 短驗證，保存完整目錄與 checksum 後傳回 GB10。不同 PyTorch／CUDA／nvcc 版本須分組標記；不得把 E1 舊版不同輸入資料或 E2 smoke 納入正式曲線。5090 待設備可用。E3/E4 校正器與預測模型尚未執行。
