## 已取得的實測

- 設備：NVIDIA GB10；ResNet50 FP16 eager、224×224、batch 1／8／32；G、A、P0、P1 各三個獨立 run，共 36 個。
- 36/36 run 的 `execution.json` 與 worker 自動品質檢查通過。18/18 P0／P1 trace 的 parser 與結構檢查通過；P1 phase kernel 數與 duration 覆蓋率均為 100%。批次原始事件核對涵蓋 3,882 次正式量測 iteration，未發現結構例外。
- 18/18 trace 仍有 Nsight「Not all CUDA events might have been collected」警告；其中九個 P1 另有 NVTX 同類警告。沒有明確非零 incomplete CUPTI dropped-event 數。這些證據不能證明零事件遺失，E1 trace 完整性仍為**待審**。
- 另做三份 B1/P1 短診斷；不同 Nsight 版本與結束方式仍未消除泛用警告。短診斷不是原 36-run session 的替代樣本。
